# Boletín CIAI

Repositorio del boletín semanal del Centro de Inteligencia Artificial e Innovación (CIAI) — Universitaria Tecnológica de Santander.

## Estructura

```
bciai/
├── assets/
│   └── uts_logonegro.png
└── ediciones/
    └── 2026-10/
        ├── main.tex
        ├── referencias.bib
        └── proyectos/
```

## Flujo de trabajo

1. Cada edición vive en su carpeta `ediciones/YYYY-MM/` o `ediciones/YYYY-MM-semanaX/`
2. Los proyectos CIAI se entregan como archivos `.tex` en la carpeta `proyectos/`
3. Las referencias se entregan en formato `.bib` y se agregan a `referencias.bib`
4. El PDF se compila en Overleaf
